# SyncPlayer

A zero-buffer local web application that hosts media from a laptop and synchronizes playback across multiple mobile devices on the same local network.

## Prerequisites
* [Node.js](https://nodejs.org/) installed on your machine.
* All devices must be connected to the same Wi-Fi/Local Network.

## Installation

1. Clone this repository or download the ZIP file.
2. Open a terminal in the project folder.
3. Install the required dependencies:
   ```bash
   npm install
